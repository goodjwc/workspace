# 싱가포르 출장 생존영어 회화 스크립트

JWC 님 연습 정리본 — 입국심사 / 택시 / 호텔 체크인 / 식당 / 점보 씨푸드
(모든 상황·답변에 한국어 번역 포함)

---

## 1. 입국심사 (Immigration)

| 심사관 / 상황 | 내 답변 |
|---|---|
| Passport, please. (여권 주세요.) | Here you go. (여기요.) |
| What's the purpose of your visit? (방문 목적이 뭐예요?) | I'm here for a business conference. (출장, 컨퍼런스 참석이에요.) |
| Business or holiday? (출장이에요, 여행이에요?) | Business. (출장이요.) |
| How long are you staying? (얼마나 머무세요?) | Five days. (5일이요.) |
| Where are you staying? (어디 묵으세요?) | At the Kingston Hotel. (킹스턴 호텔이요.) |
| Have you been to Singapore before? / Is this your first visit to Singapore? (싱가포르 와보셨어요? / 처음이세요?) | No, it's my third time. (아니요, 세 번째예요.) |
| What's the name of the conference? (컨퍼런스 이름이 뭐예요?) | It's an AI conference. Here's my invitation. (AI 컨퍼런스예요. 초청장 여기 있어요.) |
| Who do you work for? (어디서 일하세요?) | I work for Metanet, a Korean IT company. (한국 IT회사 메타넷이요.) |
| When are you flying back? (언제 돌아가세요?) | On October second. (10월 2일이요.) |
| Do you have a return ticket? (귀국 항공권 있으세요?) | Yes, here it is. (네, 여기요.) |
| Did you fill out the SG Arrival Card? (입국카드 작성하셨어요?) | Yes, I did it online. (네, 온라인으로 했어요.) |
| Are you traveling alone? (혼자 오셨어요?) | Yes, I am. / No, with my colleague. (네, 혼자요. / 아니요, 동료랑요.) |
| Is anyone else traveling with you? (동행자 있으세요?) | Yes, I'm traveling with three colleagues. (네, 동료 세 명과 함께 왔어요.) |
| Do you have any checked baggage? (위탁 수하물 있으세요?) | Yes, I do. (네, 있어요.) |
| How many bags do you have? (가방 몇 개 있으세요?) | One bag. (한 개요.) |
| What's inside this bag? (이 가방 안에 뭐가 있어요?) | My clothes and cosmetics. (제 옷이랑 화장품이에요.) |
| Are you carrying any food or plants? (음식이나 식물 가져오셨어요?) | No, I'm not. (아니요.) |
| Anything to declare? (신고할 물건 있어요?) | No, nothing. (아니요, 없어요.) |
| Do you have any electronic devices to declare? (신고할 전자기기 있으세요?) | No, I don't. (아니요, 없어요.) |
| How much cash are you carrying? (현금 얼마나 갖고 계세요?) | About one thousand dollars. (약 천 달러요.) |
| Please step aside for a random check. (무작위 검사가 있으니 옆으로 비켜주세요.) | Okay. (네.) |
| Look at the camera, please. (카메라 봐주세요.) | Okay. (네.) |
| (못 알아들었을 때) | Sorry, could you say that again? (죄송한데, 다시 말씀해 주시겠어요?) |
| Enjoy your stay in Singapore. (싱가포르에서 좋은 시간 보내세요.) | Thanks a lot. (감사합니다.) |

**팁:** 귀국 날짜는 실제 일정에 맞게 바꾸기. 담배·껌 반입 규정이 엄격하니 "nothing to declare"는 정말 없을 때만.

## 2. 택시 / Grab

| 기사 / 상황 | 내 대사 |
|---|---|
| Where to? (어디 가세요?) | The Kingston Hotel, please. (킹스턴 호텔이요.) |
| (주소 보여줄 때) | Here's the address. (여기 주소예요.) |
| Any luggage? (짐 있어요?) | Yes, two bags. (네, 가방 두 개요.) |
| (내가 먼저) | Could you open the trunk, please? (트렁크 좀 열어주시겠어요?) |
| Are you Mr. Cho? (Grab 픽업 확인 — 조 선생님이세요?) | Yes, that's me. (네, 저예요.) |
| Where are you now? (Grab 기사가 전화 — 지금 어디 계세요?) | I'm at Door 3, Terminal 1. (1터미널 3번 출구예요.) |
| Which entrance? Front or side? (정문이요, 옆문이요?) | The main entrance, please. (정문이요.) |
| (소요시간 묻기) | About how long to get there? (얼마나 걸려요?) |
| Traffic's quite bad now. (지금 좀 막혀요.) | That's okay. No rush. (괜찮아요. 급하지 않아요.) |
| (에어컨 조절) | Could you turn down the aircon a bit? (에어컨 좀 약하게 해주시겠어요?) |
| Is this your first time here? (여기 처음이에요?) | No, it's my third time. (세 번째예요.) |
| (결제) | Can I pay by card? (카드 돼요?) |
| There's a surcharge for card. (카드는 수수료 붙어요.) | That's fine. (괜찮아요.) |
| (내릴 곳) | You can drop me here. (여기서 내려주세요.) |
| (내리며) | Keep the change. Thanks! (잔돈은 괜찮아요. 감사합니다!) |

**팁:** 공항 출구는 "Door + 번호"로. aircon은 에어컨의 일반 표현.

## 3. 호텔 체크인·체류

| 직원 / 상황 | 내 대사 |
|---|---|
| Checking in? (체크인하세요?) | Yes, I have a reservation under Cho. (네, 조로 예약했어요.) |
| May I see your passport? (여권 볼 수 있을까요?) | Sure, here you go. (네, 여기요.) |
| We need a deposit on your card. (카드로 보증금 걸게요.) | Okay. How much is it? (네, 얼마예요?) |
| Your room isn't ready yet. (방이 아직 준비 안 됐어요.) | Can I leave my bags here? (짐 좀 맡길 수 있을까요?) |
| We'll text you when it's ready. (준비되면 문자 드릴게요.) | I don't have a local number. Can you use WhatsApp? (현지 번호가 없어요. 왓츠앱 되나요?) |
| Any room preference? (원하는 방 있으세요?) | A high floor with a city view, if possible. (가능하면 고층 시티뷰로요.) |
| (조식 시간) | What time is breakfast? (조식 몇 시예요?) |
| (조식 장소) | Where is breakfast served? (조식은 어디서 해요?) |
| (와이파이) | What's the Wi-Fi password? (와이파이 비번이 뭐예요?) |
| (체크아웃 시간) | What time is check-out? (체크아웃 몇 시예요?) |
| (레이트 체크아웃) | Could I get a late check-out? (늦게 체크아웃해도 될까요?) |
| (카드키 문제) | My key card isn't working. (카드키가 안 돼요.) |
| (수건 요청) | Could I get some extra towels? (수건 좀 더 주시겠어요?) |
| (에어컨 고장) | The aircon in my room isn't working. (방 에어컨이 안 돼요.) |
| (체크아웃 후 짐 보관) | Can you keep my bags until 6 p.m.? (6시까지 짐 좀 맡아주실래요?) |

**팁:** 예약자 이름은 "under + 성"으로. 방 번호 문제는 "My room is 1205." 처럼 번호부터.

## 4. 식당 (일반)

| 직원 / 상황 | 내 대사 |
|---|---|
| How many? (몇 분이세요?) | Two, please. (두 명이요.) |
| Do you have a booking? (예약하셨어요?) | No, we don't. Is there a wait? (아니요. 기다려야 해요?) |
| About 20 minutes. (20분 정도요.) | That's fine. We'll wait. (괜찮아요. 기다릴게요.) |
| Indoor or outdoor? (실내요, 야외요?) | Indoor, please. (실내요.) |
| Can I get you any drinks? (음료 드릴까요?) | Just water, please. (물이면 돼요.) |
| Still or sparkling? (일반 물이요, 탄산수요?) | Still is fine. (일반 물이요.) |
| (추천 물어보기) | What do you recommend? (뭐가 맛있어요?) |
| (양 확인) | Is this enough for two? (두 명이 먹기 충분해요?) |
| (맵기) | Is it spicy? / Less spicy, please. (매워요? / 덜 맵게 해주세요.) |
| Ready to order? (주문하시겠어요?) | Yes, we'll have this and this, please. (이거랑 이거 주세요.) |
| How's everything? (식사 괜찮으세요?) | Everything's great, thanks. (다 좋아요.) |
| (추가 주문) | Could we get one more, please? (하나 더 주시겠어요?) |
| (포장) | Can I get this to go? (이거 포장돼요?) |
| (계산) | Can we get the bill, please? (계산서 주시겠어요?) |
| (나눠 계산) | Can we split the bill? (따로 계산 돼요?) |

**팁:** 메뉴판의 "++"는 봉사료 10%+GST 별도. 팁은 따로 안 줘도 됨.

## 5. 점보 씨푸드 (칠리크랩)

| 직원 / 상황 | 내 대사 |
|---|---|
| Do you have a reservation? (예약하셨어요?) | Yes, under Cho, for two at seven. (네, 조로 7시에 두 명이요.) |
| (예약 없을 때) | How long is the wait? (얼마나 기다려야 해요?) |
| Here's your queue number. (대기번호예요.) | Thanks. Will you call us? (감사해요. 불러주시나요?) |
| (크랩 가격) | How much is the crab today? (오늘 크랩 가격이 얼마예요?) |
| It's seasonal price, by weight. (시가, 무게로 계산해요.) | How much for one kilo? (1킬로에 얼마예요?) |
| (크기 확인) | How big is the crab? Is it enough for two? (얼마나 커요? 두 명 충분해요?) |
| Chili or black pepper? (칠리요, 블랙페퍼요?) | Chili crab, please. (칠리크랩이요.) |
| (맵기 확인) | Is the chili crab very spicy? (칠리크랩 많이 매워요?) |
| Would you like some mantou? (만터우 드릴까요?) | Yes, six fried mantou, please. (네, 튀긴 만터우 6개요.) |
| Any other dishes? (다른 요리는요?) | Some fried rice and cereal prawns, please. (볶음밥이랑 시리얼 새우 주세요.) |
| (소요시간) | How long will the crab take? (크랩 얼마나 걸려요?) |
| (냅킨) | Could I get some more napkins? (냅킨 좀 더 주시겠어요?) |
| (장갑·도구) | Could we get some gloves, please? (장갑 좀 주시겠어요?) |
| (소스용 만터우 추가) | Could we get more mantou for the sauce? (소스 찍을 만터우 더 주세요.) |
| (물수건 확인) | Are the wet towels free? (물수건 무료예요?) |
| (계산) | Can we get the bill, please? (계산서 주세요.) |

**팁:** 땅콩·물수건이 자동으로 나오고 요금이 붙기도 함 — 원치 않으면 "No peanuts, thanks." 크랩은 무게 따라 가격 차이가 크니 주문 전 1킬로 가격 꼭 확인.

## 자주 틀리는 부분 체크리스트

1. **복수형 -s 빠짐**: two bag → two bag**s**, steak → steak**s**, napkin → napkin**s**
2. **I like → I'd like**: "아이드 라이크"로 붙여서 짧게
3. **work/walk, lead/need 발음 혼동** 주의
4. **at 빠뜨리기**: staying **at** the hotel, **at** seven
5. **어순**: Here is it ✗ → Here it is ✓ / pick up later ✗ → pick **them** up later ✓
6. **Do로 묻고 Do로 답하기**: Do you have…? → Yes, I do. / No, we don't.
7. **luggage는 셀 수 없음**: two luggage ✗ → two bags ✓
8. **for 발음**: "부엌"이 아니라 "포"(입술을 동그랗게)

## 매일 반복할 핵심 10문장

1. I'm here for a business conference. (출장, 컨퍼런스 참석이에요.)
2. I'll be staying at the Kingston Hotel. (킹스턴 호텔에 묵을 거예요.)
3. No, it's my third time. (아니요, 세 번째예요.)
4. To the Kingston Hotel, please. (킹스턴 호텔로 가주세요.)
5. Yes, two bags, please. (네, 가방 두 개요.)
6. Here it is. (여기요.)
7. I don't have a local number. Can you use WhatsApp? (현지 번호가 없어요. 왓츠앱 되나요?)
8. I'd like some water, please. (물 주세요.)
9. Could I get the bill, please? (계산서 주시겠어요?)
10. How big is the crab? Is it enough for two? (크랩 얼마나 커요? 두 명 충분해요?)

→ 하루 10분, 소리 내어 20번씩 반복.
