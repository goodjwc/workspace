# 🇸🇬 싱가포르 출장 생존영어 (PWA)

`script.md`(싱가포르 출장 생존영어 회화 스크립트)를 모바일에서 암기할 수 있게 만든 설치형 웹앱입니다.
빌드 과정과 외부 라이브러리가 없는 순수 HTML/CSS/JS 앱입니다.

## 기능

- **플래시카드**: 상황별 카드 또는 전체 카드를 섞어서 볼 수 있습니다. 앞면은 "상대 말"과 "한국어 뜻" 중에서 고릅니다. ✓ 외웠어요 / ✗ 다시 볼래요로 기록하고, "못 외운 것만" 다시 볼 수 있습니다.
- **실전 롤플레이**: 심사관·기사·직원의 말을 음성으로 듣고 대답합니다. 자막을 켜고 끌 수 있고, 힌트를 볼 수 있으며, 상황이 끝나면 평균 점수와 다시 연습할 문장을 보여 줍니다.
- **발음**
  - 원어민 음성(TTS): 기기에 내장된 음성 합성을 씁니다. 속도를 조절할 수 있고, 🐢 천천히 듣기도 됩니다. 상대 음성과 정답 음성을 따로 고를 수 있습니다.
  - 한글 발음 표기: 굵게 밑줄 친 부분이 강세입니다. 발음 팁도 함께 나옵니다.
  - 내 발음 녹음 → 원어민 음성과 연달아 들으며 비교할 수 있습니다.
  - 음성 인식 채점: 단어 일치율로 0~100점을 매기고, 빠뜨리거나 틀린 단어를 표시합니다.
- 오프라인에서도 동작하고(서비스 워커), 학습 기록은 기기에 저장됩니다(localStorage).

## 앱 주소

**https://goodjwc.github.io/workspace/sg-english/** (GitHub Pages, `main` 브랜치에서 배포)

## 실행 (로컬)

```bash
cd sg-english
python3 -m http.server 8000   # http://localhost:8000
```

## 폰에서 쓰기

녹음과 음성 인식은 **HTTPS** 주소에서만 동작합니다. 위 앱 주소를 폰 브라우저로 여세요.

- iPhone(Safari): 공유 → **홈 화면에 추가**
- Android(Chrome): 메뉴 → **앱 설치** 또는 **홈 화면에 추가**

## 브라우저별 참고

- 음성 인식(Web Speech API)은 브라우저마다 지원이 다릅니다. Chrome은 인식할 때 인터넷 연결이 필요할 수 있습니다. 지원하지 않는 브라우저에서는 녹음·비교 기능으로 대신 연습할 수 있습니다.
  출처: MDN — https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition#browser_compatibility
- 음성 목록은 기기에 설치된 음성을 따릅니다.
  출처: MDN — https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/getVoices

## 파일 구조

| 파일 | 역할 |
|---|---|
| `js/data.js` | 회화 데이터(상황·대사·번역·한글 발음·팁). 문장을 고치거나 추가하려면 이 파일을 수정 |
| `js/speech.js` | TTS, 녹음, 음성 인식, 채점 |
| `js/app.js` | 화면(홈·플래시카드·롤플레이·설정)과 학습 기록 |
| `sw.js` | 오프라인 캐시. 앱 파일을 바꾸면 `VERSION` 값을 올리기 |
| `script.md` | 원본 스크립트 |

> 대사와 한국어 번역은 `script.md` 원문을 그대로 사용했습니다. **한글 발음 표기와 발음 팁은 앱을 만들면서 추가한 참고용 표기이며**, 표준 표기법이 아닙니다.
